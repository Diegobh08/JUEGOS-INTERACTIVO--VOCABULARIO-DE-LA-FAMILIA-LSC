## 🌟 ¿Que es Entre Señas y Escaleras: La Casa Familiar?

**La Casa de las Señas** es una plataforma educativa e interactiva diseñada para fomentar el aprendizaje de la Lengua de Señas Colombiana (LSC), mediante juegos, actividades visuales y recursos audiovisuales relacionados con el vocabulario de los miembros de la familia.

La plataforma busca convertir el aprendizaje en una experiencia dinámica y entretenida, permitiendo que los usuarios reconozcan, practiquen y refuercen diferentes señas a través de actividades lúdicas.

Su propósito es promover la comunicación inclusiva, despertar el interés por la LSC y contribuir al reconocimiento de la diversidad lingüística y cultural.

## 🎯 Objetivo

Desarrollar una herramienta digital educativa que facilite el aprendizaje del vocabulario familiar en Lengua de Señas Colombiana, utilizando recursos interactivos que promuevan la participación, la comprensión y la inclusión social.

## 🎮 Actividades y funcionalidades

La plataforma integra diferentes recursos para fortalecer el proceso de aprendizaje:

- **Juegos interactivos:** actividades dinámicas para poner a prueba los conocimientos adquiridos.
- **Vocabulario familiar:** reconocimiento de palabras relacionadas con los integrantes de la familia.
- **Imágenes de señas:** recursos visuales para identificar las representaciones de cada palabra.
- **Videos educativos:** material audiovisual para observar la ejecución de diferentes señas.
- **Árbol familiar:** actividad para reconocer y relacionar los integrantes de una familia.
- **Preguntas y desafíos:** ejercicios de asociación, identificación y comprensión del vocabulario.
- **Escaleras y serpientes:** dinámica de juego que incorpora preguntas y retos educativos.

## 🤟 Vocabulario de aprendizaje

Entre las palabras y expresiones trabajadas se encuentran:

- Abuelo y abuela.
- Papá y mamá.
- Hermano y hermana.
- Hijo, bebé y nieto.
- Tío, tía, primo y sobrino.
- Esposa, novio y cuñado.
- Amigo y familia.
- Padrino y suegro.
- Matrimonio civil y matrimonio católico.

## 🚀 Instalación y ejecución

Para ejecutar el proyecto localmente, necesitas tener instalado Node.js.

**1. Clonar el repositorio:**

```bash
git clone https://github.com/Diegobh08/JUEGOS-INTERACTIVO--VOCABULARIO-DE-LA-FAMILIA-LSC.git
```

**2. Ingresar al proyecto:**

```bash
cd JUEGOS-INTERACTIVO--VOCABULARIO-DE-LA-FAMILIA-LSC
```

**3. Instalar dependencias:**

```bash
npm install
```

**4. Ejecutar en modo desarrollo:**

```bash
npm run dev
```

**5. Generar la compilación:**

```bash
npm run build
```
